# Портфолио разработчика — прототип

Рабочий прототип персонального сайта: монохромная «инженерная» эстетика, крупная типографика, гибридная навигация по разделам и отдельным страницам проектов.

Стек: Vite, Bootstrap 5, SCSS, нативный JavaScript. Фоновая сцена вынесена на отдельный canvas и не пересоздаётся при переходах между разделами.

## Запуск

```bash
npm install
npm start
```

Сборка:

```bash
npm run build
```

Готовые файлы складываются в `dist/`. Для статического хостинга с SPA-маршрутами предусмотрен `404.html`-fallback.

## Маршруты

- `/` — главная;
- `/about` — обо мне;
- `/projects` — каталог проектов;
- `/projects/:slug` — страница проекта;
- `/skills` — навыки;
- `/goals` — цели;
- остальные адреса — страница 404.

## Где менять контент

- `src/js/data/site.js` — имя, роль, контакты, навигация;
- `src/js/data/projects.js` — проекты, их описания и блоки;
- `src/js/data/about.js` — биография и этапы;
- `src/js/data/skills.js` — навыки и легенда;
- `src/js/data/goals.js` — цели и направления.

Верстка блоков находится в `src/js/render/`, стили — в `src/scss/`, фон — в `src/js/background/`.

## Плейсхолдеры

Перед публикацией нужно заменить:

- имя и фамилию;
- email `hello@example.com` и Telegram-ссылку;
- названия, описания и факты проектов;
- демонстрационные данные графика;
- неподтверждённые результаты, помеченные как `[факт]`.

## Фон

- `?bg=off` — полностью отключает canvas;
- `?bg=low` — принудительно включает упрощённый режим;
- при `prefers-reduced-motion: reduce` анимация останавливается.

Сцена находится в `src/js/background/placeholder-scene.js` и может быть заменена без изменения роутера и разметки.
